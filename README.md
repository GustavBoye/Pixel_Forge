PixelForge

PixelForge is a browser-based pixel art and image editing tool built with HTML, CSS, and JavaScript. It provides a lightweight, Photoshop-like interface for working with layers, drawing tools, filters, and image adjustments directly in the browser.

Features
Layer-based editing system (add, duplicate, merge, delete layers)
Brush, eraser, fill, shape, and selection tools
Text layer support with full styling controls
Image import via drag & drop or file upload
Adjustments: brightness, contrast, grayscale, invert, sepia
Filters: blur, sharpen, vignette
Layer blending modes and opacity control
Undo / redo support
Export as PNG or JPEG
Zoom and canvas fitting tools
Context menus and keyboard shortcuts

Clone or download the project
Open index.html in your browser
Start drawing or editing images immediately

No build tools or dependencies required.
